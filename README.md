# 童話家族 · Fairyland Family

以工作製作、五角色分工與玩家互動為核心的童話延伸文字網路遊戲。

目前階段：需求與接手資料建立中，尚無可執行遊戲。以下區分玩家提出的方向與待試玩的建議，不代表所有規則已定案。

## 玩家提出的方向

- 每位玩家初始可建立五個角色，分開工作或組隊探險。
- 透過伺服器執行持續工作，讓玩家關閉網頁與電腦後仍能取得進度。
- 以文字介面低成本驗證老玩家是否有興趣，工作製作是重要玩法。
- 取消職業限制：角色可使用各系戰鬥技能；對應武器強化威力並提供熟練度成長。帶幻獸戰鬥可成長幻獸相關能力。
- 希望單體技能能透過連擊與轉移目標清理怪群；範圍技能依最大目標數限制追加次數，具體機制待設計。
- 點 NPC 後，依路徑與移動時間抵達再互動；未來可點角色觀察地圖與戰鬥畫面。
- 官方允許下的整合是遠期可能性；近期以獨立延伸遊戲為主。

## 建議的第一個可玩版本（尚待實作與試玩）

先建立小型生活圈，驗證「安排工作 → 離線執行 → 回來收成果 → 與別人交換」的循環。

1. 帳號與五角色；角色一次只能執行一種活動。
2. 家族共用倉庫與金錢，先做一條「挖礦 → 冶煉 → 鍛造」生產鏈。
3. 工作排程、停止條件與成果日誌；重新登入可查看目前進度。
4. 至少兩個帳號之間的市集交易與簡單世界聊天。
5. 文字移動倒數與 NPC 互動；先限定一個村莊及少量工作地點。

完整戰鬥、跨玩家組隊、代工委託、圖像觀察、公會與世界首領分階段擴充。這個先後順序是開發建議，不是刪除需求。

第一個版本需驗證：

- 關閉瀏覽器後，伺服器仍持續工作；重新登入的成果正確。
- 伺服器重啟後，可恢復工作且不重複發獎勵。
- 角色不能同時探險與採集；無材料、無空間或其他停止條件成立時會停工並說明原因。
- 扣料、產出與交易具一致性；重送請求不重複扣款或增發物品。
- 玩家只能操作自己的角色、物品與訂單；兩人同時購買同一批貨不會重複成交。
- 電腦關機後繼續工作，需要遊戲伺服器部署在持續在線的主機；開發代理本身不等於遊戲伺服器。

## 資料與架構原則

- 伺服器決定遊戲時間、活動、資源與戰鬥結果；前端呈現倒數、文字與動畫。
- 網路連線不承載角色的生命週期；斷線不銷毀工作。
- 移動依可行走路徑計時。遇敵、取消或改目的地時，原抵達事件需失效。
- 文字與圖像觀察使用同一份狀態與事件；看畫面不改變結算速度。
- 保留來源 ID 與資料版本；區分原版提取、推測與家族版自訂。
- 名稱表不等於完整規則。配方需轉成材料 ID／數量，補齊時間、需求、產物與消耗。
- 不把示範配方、替代素材或未量測的容量寫成已確認的原版能力。

## 尚未定案

- 跨武器技能的傷害基準、解鎖條件與熟練度規則。
- 連擊是否限擊倒後追擊，或也可對同一目標續連；機率、傷害、MP 與內建多段額度。
- 工作週期、離線上限、耗材、倉庫容量與各種停止條件。
- 製作成功率、品質、耐久、定價與經濟回收方式。
- 跨玩家組隊的指令權與戰利品分配。
- 技術選型、部署、素材使用範圍與圖像觀察的交付時機。
